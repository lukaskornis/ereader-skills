# Shelf: KOReader library home screen

A full-screen library that opens over the file manager on start and whenever a book is closed. Source: `shelf.koplugin/`.

## Install
`tar cf - shelf.koplugin | ink -d kobo sh 'cd /mnt/onboard/.adds/koreader/plugins && rm -rf shelf.koplugin && tar xf -'`, then `ink restart`. While developing, `ink -d kobo reload shelf shelf.koplugin` (from `shelf/`) does both in 2 s. On the Kindle the plugins dir is `/mnt/us/koreader/plugins`.

## Files
- `main.lua`: the plugin. Registers with the file manager only (skips the reader). Shows the shelf on the next tick so it paints over the file manager in one refresh. Closes the shelf when the file manager closes, so opening a book never flashes the file browser. Starts background metadata extraction and reloads the shelf when it ends.
- `library.lua`: scans the home folder (4 levels, skips dot folders, `.sdr` and System Volume Information) for epub, pdf, djvu, fb2, mobi, azw, azw3, cbz, cbr. Metadata order: Cover Browser's `bookinfo_cache.sqlite3` (loaded through `package.path` while that plugin stays disabled), then `doc_props` in the `.sdr`, then the file name. Authors "Last, First" become "First Last"; PDF titles lose `.pages`, `.doc(x)`, `.indd`, `.pdf`. Progress comes from KOReader's `BookList` cache. Sort Read = history time, then mtime; New = mtime.
- `covers.lua`: online covers from Open Library for books without their own cover and for scans; everything else keeps its own cover. Scans: DjVu, CBZ, CBR, and PDFs whose producer is a scanning tool (Internet Archive, ABBYY, Paper Capture…) or whose first 4 pages have no text; a PDF is checked once in the subprocess (`.scan` or `.own` marker). Search is by title and author, then by exact title alone (catalog authors like "Doyle, Arthur Conan, Sir, 1859-1930" match nothing). While connected (on shelf open, after extraction, on NetworkConnected), books already extracted and without a lookup run through one subprocess: ISBN from the sidecar's `doc_props.identifiers` → `covers.openlibrary.org/b/isbn/<isbn>-M.jpg?default=false`, else `openlibrary.org/search.json` → `cover_i`, kept when one normalized title contains the other (exact title when searched without an author). M (~180 px wide) when the cover box is at most 180 px (Kindle), else L. Decoded, scaled to the cover box, grey on grey screens, saved as PNG in `<data dir>/cache/shelf-covers/<md5 of path>.png`; no match writes `.none`, retried after 7 days. The subprocess state is module-level, so it outlives the shelf when a book opens; when it ends, books that got a cover drop their cached bitmaps and the shelf reloads. Redirects (covers go to archive.org) are followed by hand: LuaSocket won't follow https ones. Titles "cover", "default", "untitled", "unknown" fall back to the file name.
- `shelfwidget.lua`: the UI. `buildGrid` draws both cover views (covers 4 across with titles on blank covers, tiles 5 across without). All sizes are mock units: one unit is screen width / 300, so the Kobo (1404) and Kindle (600) share one layout. Taps and holds hit-test registered FrameContainers (holds only those registered with `opts.book`); swipes left and right turn pages. Covers are scaled once per size, converted to the screen format and dithered once, then kept in a module-level cache (64 entries, least recently used dropped) that outlives the widget, so later opens and view switches only blit.
- `power.lua`: power save and auto light, module state so it keeps running while a book is open (started from `main.lua` on every plugin init, acts once per run; Resume re-ticks it). Broadcasts `ShelfPowerChanged`.
- `profile.lua`: per-device values, picked by `Device:isKobo()` / `isKindle()` and file existence, never model names. Home and Send folder (Kobo `/mnt/onboard` and `/mnt/onboard/Books`, Kindle `/mnt/us/documents` for both, hard-coded because KOReader's Kindle home is `/mnt/us`), light sensor file or nil (Kobo `als_vis_data` when present), governor file or nil, power-save governor (Kobo `interactive`, Kindle `ondemand`), bookdrop User-Agent (Kobo UA so EPUBs arrive as kepub, a plain UA elsewhere so they arrive as uploaded). Not named `device.lua`: the plugin folder is first on `package.path`, so that would shadow KOReader's module.
- `clock.lua`: header clock text and the trust check (year guard, then one HEAD comparing with the server `Date`).
- `icons/`: Tabler icons v3.19.0 (MIT), black, plus white `.on` variants for the active view.

## Settings (G_reader_settings)
- `shelf_view`: covers, tiles or names. `shelf_sort`: read or new. `shelf_autostart`: nil or true opens the shelf on start and after a book; toggle under File manager settings, Library shelf.
- `shelf_power_save` (bool) and `shelf_power_restore` ({wifi, light} to bring back). `shelf_light_auto`: off, schedule or sensor. `shelf_light_from` / `shelf_light_to`: minutes after midnight (default 1140 / 420).
- Dispatcher action `shelf_show` (event ShowShelf) can be bound to a gesture.
- The file browser's Home icon goes to the home folder and opens the shelf (long press still opens the folder menu).

## Time left
`Library.timeLeft` reads KOReader's `settings/statistics.sqlite3`: the book is matched by `partial_md5_checksum` from its `.sdr`, the average page time is the statistics plugin's capped sum (each page counts at most `max_sec`), and time left = (1 - percent) x pages x average. Shown only after 10 read pages; computed once per reload, for the current book only. Under an hour it shows minutes, otherwise whole hours.

## Gotchas
- `self.ui.file_chooser` is nil while plugins init; tell the file manager from the reader with `self.ui.document`.
- Covers are cached at 26% x 39% of screen width (365x548 on the Kobo), enough for the hero.
- Covers within 10% of 2:3 are stretched to fill the frame; others keep their shape, centred, and the frame hugs the image.
- Cached covers are already dithered, so their ImageWidget sets `is_icon` to skip the per-paint dither (most of the old paint time on the Kobo, which dithers in software).
- crash.log is block-buffered: a probe's `logger.info` may not appear until the buffer fills; call `io.stdout:flush()` after it.
- Icons need `alpha = true`, or the white `.on` icons paint as a white box on the black background.

- Wi-Fi button (2026-11-15, verified on the Kobo): tap toggles Wi-Fi through NetworkMgr; the icon (wifi or wifi-off) follows the NetworkConnected and NetworkDisconnected events, so it is right when Wi-Fi changes elsewhere too. Moved into Apps on 2026-11-16.
- Apps (2026-11-16, verified on the Kobo): the footer's Wi-Fi icon became an Apps icon (inverted while open). Apps swaps the body for a 4-wide tile grid: Writer (opens the typewriter page through `self.ui.typewriter`, shown only when that plugin is loaded) and Wi-Fi (icon follows the state). Not persisted: a new shelf opens on the library. The page count left the footer: small "2 / 3" just above it (9 units tall: at 12 the covers view lost its second row under the hero), blank when there is one page or in Apps. Footer tap points: see Library footer below. Wi-Fi tile toggle not tapped by me (it cuts ink's link).
- Send app (2026-11-16, verified on the Kobo): third Apps tile (book-download icon). Opens a body mode with the code in 4 boxes, auto-downloads every new file into Books through a `.part` file, reloads the library, starts metadata extraction, and shows a card (cover, title, author, size, Open). HTTP lives in `bookdrop.lua` (blocking `socket.http` over HTTPS with `socketutil` timeouts 5/10 s, downloads 10/120 s). Polls every 5 s with `UIManager:scheduleIn` only while the screen is open; X, the Apps icon or closing the shelf unschedules. Wi-Fi comes on through `NetworkMgr:runWhenConnected`. The last key is kept at module level, so reopening Send shows the same code (a reload drops it). 429 backs off 60 s: rejected generates count against the limit, so retrying every 5 s never recovered. Uploads from a script need `X-Requested-With: XMLHttpRequest` plus Origin and Referer, else 403. Gotcha: `ltn12.sink.table` returns two values; pass it in parentheses or the table spills into the next argument. bookdrop.cc is book-drop (github eitan12345om/book-drop), a fork of send2ereader. HTTPS only. Use one fixed User-Agent on every call (from `profile.lua`) (status 404s on a UA mismatch; Kobo UA also makes the server kepubify EPUBs). `POST /generate` with `X-Requested-With: XMLHttpRequest` → `{"key":"ESV4"}` (4 chars from 23456789ACDEFGHJKLMNPRSTUVWXYZ; `?abandon=<old>` drops the old key). Poll `GET /status/<KEY>` every 5 s → `{files:[{name}],urls:[]}`; 404 = expired, generate again. Download `GET /<urlencoded name>?key=<KEY>`, save under the `name` from status (non-ASCII names lack a usable Content-Disposition). Key dies after 5 min idle (polling keeps it alive) or 1 h; a file is deleted 60 s after its first download. Limits per IP per 15 min: generate 20, download 20, 3 live keys. Max 5 files per key, 50 MB each. Target folder from `profile.lua` (Kobo `/mnt/onboard/Books`); the Shelf scans the default home `/mnt/onboard` 4 levels deep, so it shows up after a library reload.
- Library footer (2026-11-16, verified on the Kobo, built without a mock): the footer's History icon became a Tabler `books` icon, inverted while the library shows; Apps stays inverted in Apps and Send. - Header clock (2026-11-16, verified on the Kobo, built without a mock): "11:40 Mon" in grey right after the title in every header (Library, Apps, Send); 12 h when `twelve_hour_clock` is set. `clock.lua` decides trust: year ≥ 2025 until checked, then one HEAD to bookdrop.cc compares the device time with the `Date` header; more than 2 min off hides it until KOReader restarts. A failed check is retried at most every 10 min (it blocks up to 5 s), and only runs when Wi-Fi is on and connected (`isOnline` resolves DNS, too slow for every rebuild). One `scheduleIn` aligned to the next minute updates the text and refreshes only the header rect; unscheduled on close, full refresh on Resume.
- Book menu (2026-11-16, verified on the Kobo, built without a mock): long-press any book (hero, strip, cover, tile, names row, Send card) opens a `ButtonDialog` titled with the book: Open, Mark as read / unread (summary status "complete" or "reading", same path as the file manager), Reset progress (stock `genResetSettingsButton`, greyed for unopened books), Book info (stock), Delete (`FileManager:showDeleteFileDialog`, so the .sdr, history and collections go too). Every change reloads the shelf. Delete and Reset tested on throwaway copies. "Send to…" (2026-11-16, verified on the Kobo, built without a mock) sits above Delete: an `InputDialog` asks for the 4-char code the other reader shows in its Send screen (case and spaces ignored, anything else than 4 letters or digits is refused), then `NetworkMgr:runWhenConnected` and `Bookdrop.upload`. The upload blocks, so an `InfoMessage` is replaced and force-repainted at every 10%, then "Sent to CODE" or a reason: 400/404 = code not found, "too big" over 50 MB (the server limit), anything else = check Wi-Fi. Works across networks through bookdrop.cc; the receiving reader's UA decides kepub conversion, not the sender's.
